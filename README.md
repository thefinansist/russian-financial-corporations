# Russian Financials Updater

Небольшая утилита для обновления сравнительной таблицы российских публичных компаний в Excel. Программа загружает рыночные и фундаментальные показатели, пересчитывает мультипликаторы и сохраняет отдельную обновлённую книгу.

## Возможности

- актуальная цена акции;
- количество акций в обращении;
- чистая прибыль LTM;
- собственный капитал;
- капитализация, P/E и P/B;
- ROE, коэффициент выплат и устойчивый темп роста;
- сохранение форматирования, формул и диаграмм исходной книги;
- CSV-журнал с источниками, пропусками и предупреждениями.

## Источники данных

- [MOEX ISS](https://iss.moex.com/iss/reference/) — основной источник котировок и биржевых параметров;
- TradingView Screener — резервный источник цены при недоступности MOEX ISS;
- публичные таблицы [Smart-Lab](https://smart-lab.ru/q/shares_fundamental/) — LTM-прибыль, капитал, ROE и выплаты.

TradingView используется через внутренний endpoint скринера и не заявляет его как официальный публичный API. Smart-Lab читается как HTML-источник, поэтому изменения разметки могут потребовать обновления парсера.

## Установка

Требуется Python 3.9 или новее.

```bash
git clone https://github.com/thefinansist/russian-financial-corporations.git
cd russian-financial-corporations
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Для Windows команда активации окружения:

```powershell
.venv\Scripts\activate
```

## Запуск

Передайте путь к книге:

```bash
python3 update_financials_open.py "/путь/к/Финансовые организации.xlsx"
```

Если файл называется `Финансовые организации.xlsx` и находится в текущей папке, путь можно не указывать:

```bash
python3 update_financials_open.py
```

Рядом появятся:

- `Финансовые организации_обновлено_open.xlsx`;
- `Финансовые организации_обновлено_open.log.csv`.

Исходный файл по умолчанию не изменяется. Для обновления на месте предусмотрен флаг `--in-place`; перед записью создаётся резервная копия `.xlsx.bak`.

## Формат книги

На листе `Лист1` ожидаются следующие столбцы:

| Столбец | Значение |
|---|---|
| A | Компания |
| B | Цена |
| C | Количество акций, млн |
| D | Прибыль LTM, млрд ₽ |
| E | Капитал, млрд ₽ |
| F | Капитализация, млрд ₽ |
| G | P/E |
| H | P/B |
| I | ROE |
| J | Устойчивый темп роста |
| K | Коэффициент выплат |

Производные показатели записываются формулами Excel:

- капитализация = цена × количество акций;
- P/E = капитализация / прибыль LTM;
- P/B = капитализация / капитал;
- устойчивый рост = ROE × (1 − коэффициент выплат).

## Настройка списка компаний

Соответствие названий строк и биржевых тикеров хранится в `companies.json`:

```json
{
  "Сбер": {
    "ticker": "SBER",
    "class_code": "TQBR"
  }
}
```

Чтобы добавить компанию, внесите её в `companies.json` и добавьте строку с тем же названием в столбец A книги. Чтобы исключить компанию из результата, удалите её строку из исходного Excel-файла.

## Проверки данных

- при отсутствии свежего значения программа сохраняет прежнее и фиксирует это в журнале;
- рассчитанная капитализация сверяется с капитализацией рыночного источника;
- ROE и устойчивый рост не рассчитываются при отрицательном собственном капитале;
- экстремальный payout при отрицательной или около нулевой прибыли отбрасывается;
- для делистингованных бумаг текущей котировки может не быть.
